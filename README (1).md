## Project Overview

This repository contains three activity-based web design case studies
developed using HTML and CSS. Each website demonstrates a simple,
user-friendly interface for a different real-world service.

## Case Study 1: Hospital Website

### Objective

To design a simple hospital website that presents departments and allows
visitors to enter appointment details.

### Main Features

-   Hospital name and department section
-   Departments such as Cardiology, Pediatrics, Orthopedics, and General
    Medicine
-   Appointment form with patient name and date fields
-   Emergency contact information

### Technologies Used

-   HTML for page structure and form elements
-   CSS for colors, spacing, borders, and layout

### Outcome

The page gives visitors a clear overview of hospital departments and
provides a basic appointment-booking interface.

## Case Study 2: Fitness Center Website

### Objective

To create a fitness center page that introduces workout programs and
membership plans.

### Main Features

-   Fitness center heading and program list
-   Strength training, cardio workout, yoga, and weight-loss programs
-   Basic and premium membership prices
-   Registration form with name and email fields

### Technologies Used

-   HTML for headings, program details, and registration form
-   CSS for the green theme, layout, and visual styling

### Outcome

The page presents fitness programs and membership options in a simple
format and lets visitors enter registration details.

## Case Study 3: Adventure and Trekking Website

### Objective

To build an adventure website that displays trekking options and basic
trip-planning information.

### Main Features

-   Trekking routes with difficulty, duration, and price
-   Mountain trekking and forest camping options
-   Equipment checklist, including a backpack, water bottle, trekking
    shoes, and first-aid kit
-   Safety guidelines
-   Trip-booking form with name and date fields

### Technologies Used

-   HTML for route information, checklists, and booking fields
-   CSS for the green theme, cards, spacing, and borders

### Outcome

The page helps visitors compare trekking activities, review essential
equipment and safety reminders, and enter trip-booking details.

## Conclusion

These three case studies demonstrate how HTML and CSS can be used to
create clear, organized web interfaces for healthcare, fitness, and
adventure services. The pages are introductory front-end designs; form
submissions would need additional backend functionality to process
bookings or registrations.
